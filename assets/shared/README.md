# Shared UI assets

Independent **reusable** decorative graphics, illustration primitives, icon exports and cross-screen backgrounds.

- [Wellness landscape PNG component kit](wellness-landscape/README.md): six transparent PNGs (hills, waves, sprout, left/right leaves) to compose a common decorative landscape behind onboarding heroes.
- [Wellness scene recipe](wellness-landscape/composition.json): reference-stage positions, dimensions and z-order for responsive assembly.
- [mint-leaf-cluster.svg](mint-leaf-cluster.svg): optional older vector decoration, **not** used at the same time as the PNG landscape kit.

Use assets from here across screens/modules without copying binaries into multiple design folders. Each feature owns its own screen-to-asset mapping. Full-screen mockups stay in the feature's screen catalog, not in `assets/shared/`. See [assets policy](../README.md) and [global mapping standard](../../ASSET_MAPPING_STANDARD.md).
