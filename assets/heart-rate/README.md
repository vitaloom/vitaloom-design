# Heart Rate artwork — current analytics refresh

**Provenance:** Independently authored, reusable vector redraws inspired by the accepted Heart Rate illustration. These are **not cropped screenshots and not identical pixel-for-pixel to the original generated raster**.

- [heart-pulse-hero.svg](heart-pulse-hero.svg) — transparent dimensional coral heart with stylized heartbeat line, artboard 320 × 300.
- [heart-hero-scenery.svg](heart-hero-scenery.svg) — translucent rose waves, botanical shapes and accent strokes, artboard 430 × 180.

Render heart artwork on the right side of hero using contain sizing; overlay it **above** the scenery, with real BPM and measured-at text above the scene, never inside the asset. The white zigzag inside the heart is **decorative illustration only, not measured ECG telemetry**.
